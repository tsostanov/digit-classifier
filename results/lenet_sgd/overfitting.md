# Анализ переобучения по фактическому запуску

Train и validation измерены на фиксированных весах после каждой эпохи в режиме eval.

Лучшая эпоха по validation loss: 10. Train loss=0.018657, validation loss=0.036532; train accuracy=99.5280%, validation accuracy=98.8700%. Разрыв accuracy=0.658 п.п.

В последнюю эпоху: train loss=0.016793, validation loss=0.037228. Эпохи с ростом validation loss при снижении train loss: [8, 11, 12].

Обнаружено локальное расхождение динамики потерь train и validation. Одиночный рост может быть флуктуацией и не доказывает устойчивое переобучение. Учитывайте величину изменений, accuracy и последующие эпохи. Используется лучший checkpoint.

Validation используется для выбора checkpoint и не является независимым итоговым тестом. Оценка собственных рисунков выполняется отдельной командой evaluate. Наборы для повторных проверок не дают независимой итоговой оценки. Для неё нужен отдельный набор рисунков.
